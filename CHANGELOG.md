# Changelog

## [Unreleased]

- Предрелизная проверка: отказ Git status теперь отменяет обновление; сбой замены каталога возвращает прежнюю версию.
- Ошибка записи кэша blocklists откатывает рабочие ipset; восстановление не удаляет recovery-код при неудаче.
- Таймер включается до настройки сервисов, повторяет неудачный откат и восстанавливается при ошибке удаления.
- Применение требует активного UFW и работающего systemd; неизвестные опции отклоняются.
- Связанные ICMP/PMTU и DHCP не попадают под anti-spoofing/эвристику сканирования.
- 30 автоматических проверок, включая настоящий локальный Git и systemd-analyze; добавлен native-netfilter gate.

- Компактное циклическое меню с обновлением и подтверждением применения.
- Обновление проекта из GitHub: проверка файлов и синтаксиса, резервная копия, защита локальных изменений.

- Прямая команда protect сохраняет ENV, включая DRY_RUN, без опроса.
- Валидация параметров, отдельные цепочки IPv4/IPv6 и структурная вставка в filter.
- Подготовка и проверка UFW-файлов до замены; снимки настроек и обработчик ошибок.
- Независимый systemd-откат, явное подтверждение из нового SSH-подключения.
- Последний успешный blocklist сохраняется при сбое источника и восстанавливается при загрузке.
- Пороговый portscan-бан выключен по умолчанию; connlimit проверяет только SYN.
- Удаление сохраняет посторонние правила UFW и восстанавливает прежние состояния сервисов.
- Исправлены определение inactive UFW, пути recent и счётчики статуса.
- Добавлены тесты с заглушками и CI; реальные netfilter/systemd и нагрузка ещё требуют проверки.
- Несовместимые изменения: обязательное подтверждение, отсутствие PURGE_CROWDSEC,
  автобан opt-in, отказ от пустых/некорректных blocklists и сокращений более 50%.

## [1.0.0] — 2026

### Добавлено
- AntiScan: автобан IP за SYN/UDP на нессервисный порт (ipt_recent, без доп. зависимостей)
- Flag-drop: XMAS, NULL, SYN+FIN, SYN+RST, FIN+RST и другие мусорные пакеты
- Anti-spoofing: RFC1918/bogon на WAN-интерфейсе (IPv4)
- Per-IP SYN-flood rate-limit через hashlimit на каждый сервисный порт
- Per-IP connlimit: ограничение одновременных соединений
- SSH per-IP rate-limit + fail2ban (бан после 5 попыток, 24ч)
- ICMP rate-limit (ping живой, флуд режется)
- CrowdSec: community blocklist + поведенческий IPS
- Whitelist: IP из списка всегда пропускаются первыми
- DRY_RUN=1: посмотреть правила без применения
- Полный откат одной командой
- Бэкап before.rules перед каждым применением
- Интерактивное меню + прямые команды
- IPv4 и IPv6 паритет

# Changelog

## [Unreleased]

- Исправлено: коллекции CrowdSec не устанавливались на актуальных версиях `cscli`
  (`unknown shorthand flag: 'q'`).
- Исправлено: Basic сообщал «SSH-ключ не добавлен» и останавливался, хотя ключ уже
  был записан (`tmp: unbound variable` в EXIT-trap). Уже существующий ключ теперь
  сообщается отдельно.
- Basic больше не прописывает `PermitRootLogin prohibit-password`: раньше drop-in
  `00-…` перекрывал `PermitRootLogin no` и снова разрешал вход root по ключу.
- Basic отказывается отключать пароль, если `AuthenticationMethods` требует не только
  ключ или root не сможет войти из-за `PermitRootLogin` (иначе — полная блокировка входа).
- `SSH_CONNECTION` восстанавливается из родительских процессов во всех режимах и в
  `confirm`: при запуске через `sudo` без `--preserve-env` проверка новой SSH-сессии
  раньше молча отключалась.
- `confirm` сообщает об уже выполненном откате вместо «нечего подтверждать».
- Portscan autoban сверяется с разрешёнными портами UFW и не применяется, если
  клиенты этих портов (например, панель → API ноды) будут забанены.
- Имена hashlimit зависят от параметров: раньше новые лимиты при повторном
  применении молча игнорировались ядром до удаления старой таблицы.
- `PORTSCAN_HITS` проверяется против ограничений `xt_recent` до изменения UFW.
- Fail2Ban: `apt-get update` перед установкой, `ignoreip` из `WHITELIST`,
  настраиваемые параметры в Basic.
- Откат отключения IPv6 возвращает статические адреса и маршруты, которые ядро
  удаляет при `disable_ipv6=1`.
- Общий lock перенесён из world-writable `/run/lock` в `/run`.
- Добавлен отдельный пункт дополнительных настроек: проверяемое включение BBR + CAKE
  и явное включение/отключение IPv6.
- Настройки ядра и IPv6 используют snapshot, persistent safety timer, ручной confirm
  и восстанавливаются при timeout, ошибке или удалении проекта.
- Отключение IPv6 блокируется, если текущая SSH-сессия работает через IPv6; CAKE
  задаётся безопасным default qdisc без принудительной замены очереди live-интерфейса.
- Protect разделён на полностью опциональный Basic и ручной Experimental.
- Basic валидирует вставленный публичный ключ, безопасно дополняет `authorized_keys`,
  проверяет эффективную конфигурацию sshd и страхует отключение пароля автооткатом.
- Safety timer стал persistent и переживает reboot; `confirm` принимает только
  SSH-сессию, созданную после применения защиты в той же загрузке системы.
- Experimental больше не включает сетевые фильтры неявно: каждая функция и её
  параметры выбираются отдельно в меню, а ENV-переключатели по умолчанию равны `0`.
- Удалены устаревшие внешние IP-списки, зависимость от ipset и их systemd-таймеры;
  повторное применение безопасно очищает артефакты предыдущих версий.
- Предрелизная проверка: отказ Git status теперь отменяет обновление; сбой замены каталога возвращает прежнюю версию.
- Восстановление не удаляет recovery-код при неудаче.
- Таймер включается до настройки сервисов, повторяет неудачный откат и восстанавливается при ошибке удаления.
- Применение требует активного UFW и работающего systemd; неизвестные опции отклоняются.
- Связанные ICMP/PMTU и DHCP не попадают под anti-spoofing/эвристику сканирования.
- 30 автоматических проверок, включая настоящий локальный Git и systemd-analyze; добавлен native-netfilter gate.

- Компактное циклическое меню с обновлением и подтверждением применения.
- Обновление проекта из GitHub: проверка файлов и синтаксиса, резервная копия, защита локальных изменений.

- Прямая команда protect сохраняет ENV, включая DRY_RUN, без опроса.
- Валидация параметров, отдельные цепочки IPv4/IPv6 и структурная вставка в filter.
- Подготовка и проверка UFW-файлов до замены; снимки настроек и обработчик ошибок.
- Независимый systemd-откат, явное подтверждение из нового SSH-подключения.
- Пороговый portscan-бан выключен по умолчанию; connlimit проверяет только SYN.
- Удаление сохраняет посторонние правила UFW и восстанавливает прежние состояния сервисов.
- Исправлены определение inactive UFW, пути recent и счётчики статуса.
- Добавлены тесты с заглушками и CI; реальные netfilter/systemd и нагрузка ещё требуют проверки.
- Несовместимые изменения: обязательное подтверждение, отсутствие PURGE_CROWDSEC,
  автобан opt-in и удаление внешних статических IP-списков.

## [1.0.0] — 2026

### Добавлено
- AntiScan: автобан IP за SYN/UDP на нессервисный порт (ipt_recent, без доп. зависимостей)
- Flag-drop: XMAS, NULL, SYN+FIN, SYN+RST, FIN+RST и другие мусорные пакеты
- Anti-spoofing: RFC1918/bogon на WAN-интерфейсе (IPv4)
- Per-IP SYN-flood rate-limit через hashlimit на каждый сервисный порт
- Per-IP connlimit: ограничение одновременных соединений
- SSH per-IP rate-limit + fail2ban (бан после 5 попыток, 24ч)
- ICMP rate-limit (ping живой, флуд режется)
- CrowdSec: community blocklist + поведенческий IPS
- Whitelist: IP из списка всегда пропускаются первыми
- DRY_RUN=1: посмотреть правила без применения
- Полный откат одной командой
- Бэкап before.rules перед каждым применением
- Интерактивное меню + прямые команды
- IPv4 и IPv6 паритет
